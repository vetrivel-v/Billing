# ADR-0005: Prisma 7 and migration policy

- Status: Accepted
- Date: 2026-10-16

## Context

Prisma 7 requires driver adapters and reads the connection URL from `prisma.config.ts`. Prisma cannot express check constraints, partial unique indexes or triggers.

## Decision

Schema at `prisma/schema.prisma`; client generated into `packages/database/src/generated` (git-ignored, regenerated by `npm run db:generate`); runtime client created via `@prisma/adapter-pg`. Migrations are generated with `prisma migrate diff`/`migrate dev` and may be extended with hand-written SQL in the same file (marked by a comment block). Applied with `prisma migrate deploy`. Forward-only; each future schema change needs a migration test (spec section 37).

## Consequences

Hand-written SQL must be kept when regenerating. Pre-migration backup and startup compatibility checks are not implemented yet (Phase 1/6).
