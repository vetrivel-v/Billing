# Quick Start

For the person who will use CommerceBill every day. (Installation: WINDOWS_INSTALLATION.md.)

1. **Open** CommerceBill from the Desktop or Start menu. Wait for the start-up window; the first start can take half a minute.
2. **Sign in** with your user name and password. The first time, the setup wizard creates your business and the administrator account. Write the administrator password down and keep it safe.
3. **Add a customer, then a product**, and enter the opening stock.
4. **Create an invoice**, check it on the preview, and post it. Until production billing is enabled every invoice is marked **DEMO** and is not a tax invoice.
5. **Save as PDF or print** from the invoice screen. **Record a payment** against the invoice.
6. **Back up** (Settings, Backup & Recovery): make a backup, **verify it**, and copy the file to an external drive. Do this at the end of every working day.
7. **Close** CommerceBill with the window's close button (X). It saves and shuts down its database by itself. Do not switch the computer off while it is open; wait until the window has closed.

If something does not start or looks wrong, read TROUBLESHOOTING.md. You can always open Settings, About & Diagnostics to see the state and save a diagnostics file for the support person.

Remember: the rates and tax settings are placeholders until your accountant has reviewed them (R-040), and a backup only on this computer is lost if the computer is lost (R-097).
